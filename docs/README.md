# Документація проєкту Slovko

## Призначення
Інженерна документація, словникові стандарти та специфікації гри у слова `Slovko`.

## Структура
- `SETUP-FIREBASE.md` — Інструкція з налаштування синхронізації та бази даних.
- `adr/` — Архітектурні рішення.
- `specs/` — Специфікації алгоритмів валідації слів та ігрових режимів.
